
# Font-Icon-Creator-Designer

Font and icon creator and designer for dot-matrix LCDs.

You can use the `font.h` and `icon.h` files generated by this application with the "STM32 Arduino LCD & Touch Driver Library" available on this site.

Simply copy the font or/and icon file into the library directory and include it in `LCD_GUI.h`. You can then use it with the following lines:

For a font:
```cpp
LCD_GUI.h
------------

#include <font19.h>

`lcd.PrintFont(font19,"I$abcdefghijklmnoprqstuvwxyz", CENTER, 156, 4, GREEN,BLUE,1);`
```

For an icon:
```cpp
LCD_GUI.h
------------

#include <icon_save.h>

`lcd.DrawIcon(icon_save,50,50,RED);`
```
